## Minor observations (non-blocking)

1. **Hardcoded version strings** — `native/src/main.rs:31` and `native/src/prepare.rs:847` (`pliron: "0.20.0"`) are independent of the Cargo pin. If the pin is ever bumped, these fields (and the `__main__.py` output that echoes them) would silently misreport the version — notable given how much the README leans on exact-version truthfulness. A build-time tie-in (e.g., `cargo:rustc-env`/`option_env!` or a check against `pliron::VERSION` if exported) would be safer.
2. **Bridge error surface** — `bridge.py:35` wraps only nonzero exit codes in `Rejected`; a missing binary raises `FileNotFoundError` and a >30s native run raises `subprocess.TimeoutExpired`. Acceptable for a research adapter; worth knowing if the CLI is used outside the test fixture.
3. **Panics inside analyses** — `DispatchAnalysis::compute`/`SourceAnalysis::compute` (`prepare.rs:599-604, 618-623`) use `unwrap()` on structure that is only guaranteed because `prepare()` builds and verifies the plan itself before running passes. Fine as an internal invariant; just don't reuse these passes on foreign input.
4. **Fused-group placement freedom** — `load()` verifies every fused group's correspondence and eligibility but (unlike the matcher) doesn't constrain *which* stages group together, so a hand-authored plan could use a grouping the rewrite wouldn't produce. This is a completeness nuance, not a soundness gap — every group is still strictly correspondence-checked — and is irrelevant while producers have exactly two stages.

## Conclusion

The experiment does what it claims and no more: real Pliron semantic/prepared ops, graph vs SSA region checks, verified strict correspondence, a real guarded fusion via `MatchRewrite`, and genuine framework-managed analysis invalidation/preservation — with B's Python runtime, bindings and independent oracle reused through a narrow process adapter. Test coverage is thorough on both positive execution and negative controls at every gate boundary, and the documentation's limits are accurate. No changes required.
