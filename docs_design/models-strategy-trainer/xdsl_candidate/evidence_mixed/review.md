## Minor findings (non-blocking)

1. **`demo.exercise` footgun** (mixed_demo.py:25): it waits on `controls.entered`, which is only ever set when `block_key` is admitted. With default `MixedControls()` (`block_key=None`) the demo times out after 10 s with a `TimeoutError` rather than a readiness failure. All current callers set `block_key=6`; a one-line guard or docstring note would help.
2. **Unfused reorder corruption is unpinned** (test_mixed_runtime.py:129–134): the `"order"` case unconditionally fetches a `FusedOp`; on an unfused plan it would `StopIteration` into a *vacuous* `NotReady`. The test always uses `fuse=True`, so the unfused document-order swap (which `mixed_adapter.py:417–421` does reject) has no direct regression case.
3. **Small semantic/target pinning gaps**: no direct test corrupts `learned.model` (rejected at mixed_contract.py:98–101) or `advance.parameter` (rejected at mixed_adapter.py:334–335). Behavior exists; only regression coverage is missing.
4. **`ack_before_next_selection` naming**: in this profile the boundary is realized as "a selection's policy reflects all feedback applied before it" (horizon-gated, validated by the oracle's clock reconstruction) rather than a mechanical wait for the previous ticket's ack before the next selection. Behavior is correct and pinned; the descriptor just suggests a stricter mechanical boundary than is enforced. Worth a sentence in the README if the descriptor vocabulary is ever formalized.
5. **Implicit scheduling invariant on clean stop**: a publication blocked at capacity (key 5) is classified as cancellation only because the existing producer machinery calls `task.cancel()` *before* `end_demand()` with no intervening loop switch, so the cancellation is delivered before the closed-feed wakeup (which would otherwise raise `NotReady("Publication after producer shutdown")` and turn the planned stop into a failure). This is sound today and is pre-existing backend behavior, but it is an unstated coupling the mixed stop path depends on; keep it in mind if the producer stop chain is ever reordered.
6. **Handoff hygiene**: `evidence_mixed/qualification.json` still records `"review": {"status": "pending"}` — update at handoff. Also note `MixedRun.run()` returns failed reports instead of raising (mirrors A's `ModelRun`; callers must inspect `status`).
