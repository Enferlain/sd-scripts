# Model, strategy and Trainer rework

Start with the [history index](history/README.md), particularly the
[carry-forward decisions](history/current-decisions.md). It connects the
original discussion, subsequent corrections and present language evidence.

and its delta specs govern further design; production G5 remains open.

The earlier direction, exchange design, inventories, discussions and provisional

Their bytes and original roles are preserved. The history's
[relocation map](history/archive-relocations.json) resolves paths in older
captures without rewriting their provenance.

The runnable evidence remains here:

- [Shared xDSL language slice](xdsl_language/README.md): current bounded

  execution and ownership mechanisms reused by later experiments.
- [xDSL candidate](xdsl_candidate/README.md) and

- [Matched machinery comparison](machinery_comparison.md) and its companion

These packages remain research evidence. Their class names, target conventions
and completed experimental milestones do not select production APIs or finish
the migration.
