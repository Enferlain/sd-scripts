## 8. Coverage and limitations

The audit pinned the branch through GitHub and built a read-only file snapshot rather than a git checkout. Its 70 fetched files were verified byte-for-byte against the recursive pinned tree's Git blob SHA-1 identities. The three recorded cost-source SHA-256 identities also matched. There was no supplied local checkout or uncommitted user patch to audit, so this report concerns the remote commit only; it makes no claim about local dirty state or a subsequently advanced branch.

Read in full for normative reconstruction: rework proposal, design, tasks and all 15 delta specs (requirements **and scenarios**); companion proposal/design/tasks and all seven delta specs; all nine available affected main specs; research index and mechanism sketch. Followed selectively: normative direction/Q1–Q5 and settled-decision sections, exchange settled inputs/disposition context, dated correction notes, implementation mapping, metadata research ledger, stronger two-pass proposal, production launcher/Trainer/phases, selected experimental code/assertions and raw cost records. Companion loader tables and broader architecture proposals were not independently re-audited against every underlying loader/upstream repository. Some long research outputs were truncated; coverage claims are confined to the primary texts and the supporting sections actually read, not every supporting file fetched.

Not independently performed: OpenSpec strict validation, pytest execution, benchmark reruns, review-mcp, full production code-graph coverage, Beads history/review verification, upstream recipe verification, rank/device/concurrency testing, complete contributor restoration, or archive/sync/apply. Recorded successful tests/reviews/validation remain repository claims; inspected test assertions establish test intent, not a fresh pass result. This is appropriate to a read-only Pass 0 but materially limits conclusions about implementation and conformance.

No main spec currently exists for the seven new rework capabilities, or for the companion's new catalog/source/structure capabilities.
